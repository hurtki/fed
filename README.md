### Ready for now

#### Bash scripts agent ( golang compiler required )

Setup env variables for gemeni or ollama as in `.env.example` in `.env`

To run agent using gemini:

```
go run ./cmd/gemeni/
```

To run agent using ollama:

```
go run ./cmd/ollama/
```
